# AI Carrier - 企业级智能基座

> 「AI 的家、AI 的工作空间、AI 的母舰」——而不是一个工作台

AI Carrier 是一个面向 AI Agent 的综合运营平台，为企业打造真正能用、会成长、能协同的通用 AI Agent。我们拒绝一堆零散、死板、只能单点使用的工具，而是构建一个完整的 AI 生态系统。

> 参考文章：[AI Carrier 平台介绍](https://blog.csdn.net/weixin_37549511/article/details/159205343)
>
> 开源地址：[github.com/mountorc/ai-carrier](https://github.com/mountorc/ai-carrier)

# 一、总体设计

> 本部分阐述 AI Carrier 的业务价值：为什么做、为谁做、解决什么问题。

## 1.1 时代背景

AI 正经历从单功能 Agent 向通用 Agent 的深刻转变，其角色从被动执行指令的工具，演变为能够主动理解、规划和执行复杂任务的智能助理。

| 阶段 | 模式 | 描述 |
|------|------|------|
| **过去** | 一人操作多个单功能 Agent | 用户需要手动操作不同的工具完成任务 |
| **现在** | 一人拥有专属的通用 AI 助理 | AI 助理理解用户意图，自动完成任务 |
| **未来** | AI 助理作为中介协调工具 | AI 助理对接和协调其他工具或 Agent |

这一转变带来了软件形态和交互方式的根本性变革：

- 传统的 Agent 和工作流将从台前转到幕后
- 传统的软件将由 For Human 转为 For Agent
- **Skill 将成为下一代应用的核心窗口**

### 企业面临的核心问题

| 问题 | 现状 | AI Carrier 的解法 |
|------|------|-------------------|
| 工具碎片化 | 一个任务需要切换多个工具 | 统一工作空间，一个母舰承载所有能力 |
| 能力不可复用 | 每次开发从零开始 | 原子化能力 + Skill 封装，一次构建处处复用 |
| Vibe Coding 不可控 | 灵活但不稳定、不可复现 | 工程化生产（Skills 工厂），标准化交付 |
| Agent 协同困难 | 多 Agent 各自为战 | 舰队编队模式，统一调度协作 |
| 扩展成本高 | 新功能需要改核心代码 | 挂载式架构，热插拔集成 |

### 舰队角色详解

| 角色 | 技术概念 | 隐喻 | 职责 | 说明 |
|------|----------|------|------|------|
| **母舰** | AI Carrier | 平台本身 | 基础设施 | 统一工作空间，提供身份认证、存储、调度等基础服务 |
| **舰队指挥** | AI Captain | 编排调度层 | 战略决策、全局指挥 | 理解用户意图，制定任务计划，分配资源，协调整个舰队的行动 |
| **工程师** | Engineer | 系统操作层 | 执行技术操作 | 负责系统级操作，如文件处理、数据操作、系统维护等 |
| **飞机** | Harness | Agent 运行框架 | 执行环境 | 为大模型提供执行环境、工具调用、上下文管理 |
| **飞行员** | 大模型 (LLM) | 智能内核 | 理解推理决策 | 负责理解用户意图、推理决策、生成响应 |
| **挂载吊舱** | Skill | 模块化能力包 | 能力封装 | 按需挂载到 Harness 上，赋予 Agent 特定领域的执行能力 |
| **弹药** | 能力 (Ability) | 原子化能力 | 基础能力单元 | 最小的可独立调用的能力单元（API、算法、规则、流程） |
| **弹药库** | 武备库 | 能力中心 | 能力存储分发 | 集中存储和管理所有可用的 Skills 和原子化能力 |
| **挂载模块** | Mounted Modules | 扩展模块 | 功能扩展 | 通过挂载式架构集成的独立系统和第三方服务 |

## 1.3 大架构理念

### mailTower —— 通信/消息层

mailTower 是平台的通信基座，负责飞行编队之间、编队与母舰之间的消息传递和通知。它是整个平台的「神经网络」，确保信息在正确的时机到达正确的节点。

- 消息路由与分发
- 事件通知与推送
- 跨模块通信协调
- 飞行编队间协作的消息总线

### Skills 工厂与武备库 —— 能力弹药体系

Skills 工厂与武备库共同构成平台的能力弹药体系，负责能力的**生产、存储、分发和消费**全链路。

**Skills 工厂（弹药生产线）**：将业务流程（SOP）与标准化的 API 或 MCP 接口相结合，自动化构建、测试、部署和优化 AI Skills（挂载吊舱）。

**武备库（弹药库）**：弹药生产完成后的归宿，集中存储和管理所有可用的 Skills（吊舱）和 Abilities（弹药），供飞机按需挂载和调用。

```
能力原子化（弹药） → Skills 工厂生产（生产线） → 武备库存储（弹药库） → 飞机按需挂载吊舱
```

### 挂载式架构 —— 扩展机制

挂载式架构是平台的技术架构基础，采用插件化、模块化设计：

- **灵活扩展**：新的吊舱（Skill）、弹药（Ability）和外部系统以「挂载」方式快速集成，无需修改核心架构
- **动态加载**：模块通过 `manifest.json` 描述自身能力，平台自动发现和注册
- **热插拔**：支持吊舱的动态挂载/卸载，不影响飞机（Harness）运行
- **能力进化**：根据业务需要，快速引入新的大模型、第三方服务或自定义吊舱

### 项目编队 —— 项目协作模式

项目编队将传统的项目管理升级为面向飞行编队的协作模式：

- 项目作为飞行编队协作的顶层组织单元
- 支持项目级别的权限隔离和资源分配
- 飞行编队可以在项目范围内领取任务、挂载吊舱、提交成果
- 项目状态的动态切换（启用/禁用）

## 1.4 协同工作流程

```
传统软件 → 功能拆解为 API（弹药） → 构建标准化 MCP 接口 → 结合 SOP 构建 Skill（吊舱）
→ Skills 工厂自动化生产 → 武备库存储 → 飞机按需挂载吊舱 → 飞行员驾驶执行任务
```

母舰（AI Carrier）提供统一的工作空间和基础服务，飞机（Harness）搭载飞行员（LLM）并挂载吊舱（Skill），吊舱内封装弹药（Ability）。整个系统通过挂载式架构实现灵活扩展，通过武备库实现能力的集中管理和按需分发。

# 二、模块功能

> 本部分阐述 AI Carrier 各模块的创新点和技术亮点。

## 2.1 AI 助理集群 —— 多编队协同

AI 助理集群是平台的核心应用层。每个 AI 助理由「飞机（Harness）+ 飞行员（LLM）+ 挂载吊舱（Skill）」组成，用户可以拥有多个这样的飞行编队。

**创新点**：
- **编队自治**：每个编队独立运行，拥有自己的吊舱配置和执行环境
- **智能调度**：根据吊舱能力匹配和负载均衡自动分配任务
- **跨编队协作**：多个编队共同处理复杂项目，无需人工协调
- **任务分解**：复杂任务自动拆解为子任务，分配给最合适的编队

## 2.2 Skills 中心（吊舱仓库）—— 能力的统一管理

Skills 中心是平台的能力中枢，负责集中管理和分发企业内部的各类挂载吊舱（Skill）。

**创新点**：
- **双模搜索**：关键词搜索 + 向量语义搜索，精准匹配需求
- **版本管理**：完整版本追踪与历史保留，支持回滚
- **反馈闭环**：吊舱使用反馈收集与统计，驱动持续优化

## 2.3 能力中心（弹药库）—— 原子化能力体系

能力中心将复杂的业务能力拆解为最小的、可独立调用的**弹药（Ability）**。

**创新点**：
- **能力原子化**：业务能力拆解为最小可复用单元
- **向量匹配**：基于语义理解的智能能力匹配
- **虚拟能力**：数据集、工作流自动注册为弹药，无需手动封装
- **能力组合**：多个原子能力灵活组合，构建复杂能力

## 2.4 Skills 工厂（弹药生产线）—— 自动化生产

Skills 工厂提供完整的工具链，用于自动化地构建、测试、部署和优化挂载吊舱（Skill）。

**创新点**：
- **SOP → Skill**：标准操作流程自动转化为可执行的 Skill
- **API/MCP → Skill**：标准化接口自动封装为 Skill
- **一键发布**：构建 → 打包 → 上传 → 注册，全流程自动化
- **持续优化**：基于使用数据的性能监控和质量优化

## 2.5 任务中心 —— 全生命周期管理

任务中心是 AI Carrier 的执行驱动引擎，负责任务的创建、分配、跟踪和协作，是连接「规划」与「执行」的核心枢纽。

**创新点**：
- **多级任务体系**：支持主任务 → 子任务的层级结构，复杂项目自动拆解为可执行的原子任务
- **角色流转机制**：任务在不同角色间自动流转（创建 → 领取 → 执行 → 评审 → 完成），每个状态变更可触发下游动作
- **编队协作**：多个飞行编队可在同一任务上协作，各自负责子任务并汇总成果
- **快捷操作**：一键领取、指派、完成，降低操作成本
- **协作评论**：任务级别的团队讨论，保留完整决策上下文
- **类型与优先级**：支持 feature / bug / optimization / research 等类型，low / medium / high / urgent 四级优先级
- **标签体系**：灵活的标签分类，便于筛选和统计

**核心能力**：

| 功能 | 说明 |
|------|------|
| 任务创建 | 指定描述、类型、优先级、执行者、时间范围、标签 |
| 子任务管理 | 主任务下拆解子任务，支持独立分配和状态追踪 |
| 状态追踪 | pending → in\_progress → completed / cancelled / failed |
| 评论协作 | 任务级别的讨论和决策记录 |
| 指派流转 | 任务在编队间流转，支持自动分配 |

## 2.6 SOP 中心 —— 标准操作流程引擎

SOP 中心是 AI Carrier 的「操作手册库」，管理企业标准操作流程，确保操作的规范性和可重复性。SOP 是 Skills 工厂的核心输入源——SOP 经过 Skills 工厂自动化生产后，转化为可被 Agent 调用的挂载吊舱（Skill）。

**创新点**：
- **SOP → Skill 转化链路**：标准操作流程通过 Skills 工厂自动转化为可执行的 Skill，这是平台「能力弹药体系」的关键一环
- **流程模板化**：SOP 可复用为流程模板，不同业务场景基于模板快速定制
- **结构化存储**：SOP 以结构化方式存储，支持版本管理和历史回溯
- **Agent 可读**：SOP 以 Agent 可理解的格式存储，飞行员可直接读取和执行

**核心能力**：

| 功能 | 说明 |
|------|------|
| SOP 管理 | 创建、编辑、归档标准操作流程 |
| 模板复用 | 基于已有 SOP 快速创建新流程 |
| 版本管理 | SOP 变更历史追踪和回滚 |
| Skill 转化 | 与 Skills 工厂联动，SOP 自动转化为可执行吊舱 |

**SOP 在平台中的位置**：

```
业务流程标准化（SOP）→ Skills 工厂自动化生产 → 挂载吊舱（Skill）→ 飞机按需挂载 → 飞行员执行
```

## 2.7 ANX 交互协议 —— AI 原生通信标准

ANX（Agent Node eXecution）是专为 AI Agent 设计的标准化交互协议和表单交互引擎。

**创新点**：
- **Markup 定义表单**：声明式表单结构，AI 可直接理解和操作
- **CLI 命令驱动**：`anx <cardKey> <command>` 格式，AI 天然友好
- **页面实例隔离**：`uuid_page` 维护稳定状态，支持多实例并行
- **Tile 系统**：多页面、多访问者的独立表单实例

**核心 API**：`getMarkup`、`execute-cli`、`update-node-data`、`getNodes`、`trigger-card-key`

## 2.8 工作流引擎 —— 流程编排与自动化

工作流引擎负责编排复杂的业务流程，实现自动化执行。

**创新点**：
- **可视化编排**：拖拽式工作流设计
- **自动注册**：工作流自动注册为虚拟能力，可被 Agent 调用
- **状态追踪**：完整的执行状态监控和日志

## 2.9 角色管理 —— 版本化岗位定义

角色管理定义和管理岗位角色，支持角色版本控制。

**创新点**：
- **版本控制**：角色定义支持版本历史和回滚
- **版本对比**：不同版本间的能力差异对比

## 2.10 调度中心 —— 定时任务管理

调度中心管理定时任务和调度策略。

**创新点**：
- **策略化调度**：灵活的调度策略配置
- **执行监控**：实时监控任务执行状态

## 2.11 数据中心 —— 数据集与数据服务

数据中心管理数据集和数据服务。

**创新点**：
- **数据即弹药**：数据集自动注册为虚拟能力，Agent 可直接调用
- **SDK 集成**：统一的数据服务 SDK

## 2.12 Storage —— 统一文件存储

Storage 提供统一的文件存储服务，支持 MinIO 和 OSS 双存储方案。

**创新点**：
- **双存储冗余**：MinIO + OSS 双活，数据安全有保障
- **零 OAuth 上传**：通过 storage token 直接上传，Agent 无需额外认证
- **短时访问 Token**：支持时间、次数、IP 三重限制的临时访问凭证

## 2.13 身份与权限 —— 多级安全体系

平台提供完整的身份认证和权限管理体系。

**创新点**：
- **一步入网**：编队报道 = 激活身份 + 注册 + OAuth 登录，一步完成
- **维度化权限**：module / api / data / ability / workflow 五维权限模型
- **Token 自动刷新**：Access Token 过期后自动使用 Refresh Token，无需重新认证

## 2.14 项目编队 —— 项目级协作

项目编队提供项目级别的组织和管理能力。

**创新点**：
- **编队协作空间**：项目作为多个飞行编队的协作顶层
- **API 验证**：项目级别的 API 可用性验证
- **动态切换**：项目状态实时切换，控制资源分配

## 2.15 创意工坊 —— 创意收集与管理

创意工坊用于收集和管理创意想法，作为能力沉淀的起点。

## 2.16 应用广场 —— 能力对外展示

应用市场展示和分发平台应用，是 Skills 和能力的对外展示窗口。
